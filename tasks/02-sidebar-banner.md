# 02 — Sidebar sign-in banner (collapsed) ✅

**Status:** shipped to main.

When the sidebar is collapsed, the signed-out "Sign in to keep it" notice moves to a frozen top-of-page dock (its own `#kq-dock-banner` slot, above any page header so it doesn't collide with the Library's search). Expanded → notice stays in the sidebar. Signed-in → nothing.
